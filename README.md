# Mushak's Modak Run

A local, original Ganesh Chaturthi festival-themed route game. Guide Mushak around a fixed courtyard, collect modaks, and bring them to the pandal within 60 seconds.

## Run

```sh
npm install
npm run dev
```

Open the URL Vite prints (normally `http://localhost:5173`). Build with `npm run build`; run rules checks with `npm test`.

## Controls

Arrow keys or WASD move Mushak. On phones, use the on-screen direction buttons. Mushak carries six modaks maximum; entering the pandal delivery area unloads the basket. Click/tap starts, resumes, or retries. The Sound button enables optional original synthesized cues.
